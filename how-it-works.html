HOW IT WORKS

From Photograph to Screening Result

A simple four-step academic demonstration workflow.

01

Capture / Upload

User uploads an image or captures one using the device camera.

02

Image Quality Check

The browser checks basic dimensions, brightness and blur indicators.

03

Demo AI Screening

A deterministic frontend demonstration pipeline analyzes visual characteristics.

04

Screening Result

The system provides a risk-oriented demo result and recommends professional evaluation when appropriate.

IMPORTANT

Demo output is not a diagnosis.

The prototype is designed to demonstrate computer-vision concepts, not to replace clinical examination or validated medical devices.
